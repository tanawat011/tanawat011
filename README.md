## 🌌 `> ls ~/vtx`

> 🧪 _The tools I use every day, so I built my own. Eleven desktop apps in Rust + Tauri, one element each, all built solo._

| App | What it does |
|---|---|
| <img src="assets/icons/lapis.png" width="22" align="top" alt=""> **Lapis** · _stone_ | Database client. PostgreSQL, MySQL / MariaDB, SQLite, SQL Server, MongoDB and Redis in one window. |
| <img src="assets/icons/fulmen.png" width="22" align="top" alt=""> **Fulmen** · _lightning_ | API client. HTTP, GraphQL, WebSocket, gRPC, SSE and MCP. Requests leave from Rust, not a browser. |
| <img src="assets/icons/silva.png" width="22" align="top" alt=""> **Silva** · _wood_ | Git client. Every action can be undone, and it runs your own git: hooks, LFS and signing included. |
| <img src="assets/icons/ventus.png" width="22" align="top" alt=""> **Ventus** · _wind_ | SSH client. Reads your `~/.ssh/config` and agent, and checks the host key before sending anything. |
| <img src="assets/icons/ignis.png" width="22" align="top" alt=""> **Ignis** · _fire_ | Dev toolbox. Paste anything and it knows what it is: JSON, JWT, Base64, timestamps, cron, cURL. |
| <img src="assets/icons/aqua.png" width="22" align="top" alt=""> **Aqua** · _water_ | Mac cleaner that knows a developer's disk: build folders, tool caches, simulators, Docker. |
| <img src="assets/icons/cuprum.png" width="22" align="top" alt=""> **Cuprum** · _copper_ | Code editor that traces where your data goes. A personal build. |
| <img src="assets/icons/lux.png" width="22" align="top" alt=""> **Lux** · _light_ | Video maker. Short videos from a script, with a live preview of every scene. A personal build. |
| <img src="assets/icons/mercurius.png" width="22" align="top" alt=""> **Mercurius** · _quicksilver_ | Mail. Gmail and Outlook accounts in one inbox, stored on your Mac. A personal build. |
| <img src="assets/icons/crystallum.png" width="22" align="top" alt=""> **Crystallum** · _crystal_ | Remote desktop from your Mac to a Windows PC. A personal build. |
| <img src="assets/icons/ros.png" width="22" align="top" alt=""> **Ros** · _dew_ | Notes as plain Markdown files that the other apps write into. |

<sub>Cuprum, Lux, Mercurius and Crystallum are personal builds. Sorry, you'll probably never get to use them 😏</sub>

- 🔌 **No account. No cloud. No tracking.** Everything they keep stays on your own machine, and they go online only for what you connect them to or ask them to do. The one extra: four of them check for updates once a day, and you can turn that off.
- 🔍 **They show their work.** Silva lists every git command it runs, and Aqua says why each item is safe to remove.
- ↩️ **Mistakes come back.** Silva can undo any action, and Lapis keeps the SQL that reverses each write.

> Most of the family is private while it grows. Lapis and Fulmen have public preview builds at [**vtx-lapis-release**](https://github.com/tanawat011/vtx-lapis-release) and [**vtx-fulmen-release**](https://github.com/tanawat011/vtx-fulmen-release), and free web tools plus the whole family live at [**vtxlabs.app**](https://vtxlabs.app/).
